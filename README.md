This repository provides R code implementing the **functional synthetic control (FSC)** methods proposed in the following paper:

This repository includes the following files, which can be used to replicate the results reported in the paper:

- `helper_functions.R`: Helper functions used in `main_functions.R`
- `main_functions.R`: Implementation of the proposed FSC methods
- `simulation_auto.R`: Script to replicate the simulation results in Section 5 under the autoregressive model 
- `simulation_factor.R`: Script to replicate the simulation results in Section 5 under the factor model 
- `fertility.R`: Script to replicate the empirical illustration in Section 6.1
- `asfr.RData`: Dataset used in `fertility.R`
- `mortality.R`: Script to replicate the empirical illustration in Section 6.2
- `aad.RData`: Dataset used in `mortality.R`
- `service.R`: Script to replicate the empirical illustration in Section 6.3
- `service.RData`: Dataset used in `service.R`
